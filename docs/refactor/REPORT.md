## 4. Decisions and Express endpoints

All 35 ADRs are indexed in [DECISIONS.md](DECISIONS.md). Highlights:
- **Seams (ADR 0102/0103/0105):** legacy module paths (`server/supabase.js`, `lib/redis.js`, `lib/gameStore.js`, `services/*.js`) stay as thin facades, because tests `jest.mock` them; `src/index.js` gets its infrastructure through them.
- **Server config (ADR 0101):** read at call time, because tests change env vars per test.
- **Server services (ADR 0103):** factories with injected dependencies and an emitter port, without receiving `io` or sockets. `now`/`random` default to call-time `Date.now`/`Math.random`.
- **Frontend identity (ADR 0202):** two cookie-identity variants kept, because they differ in one edge case.
- **Effect dependencies (0212, 0231, 0250):** legacy dependency lists kept with reasoned `eslint-disable`s, so effects re-run exactly as before.
- **Dead code deleted:** the profile edit modal (0230), `lib/supabase/server.ts` (0260), the unreferenced `RatingBadge` component and several unused lobby handlers.
- **Engine (ADR 0301/0303):** dependencies are resolved late through `main` so test patches still apply; B904 exception chaining applied (tracebacks only).
- **Tooling (ADR 0002):** Prettier is enforced on refactored paths only; `no-console` stays off because logs count as behaviour.

## 6. Deviations, partial work and risks

- **Rulebook deviations:**
  - NODE-20 (pino), NODE-05 (validated, canonical env names), NODE-02 (Express 5), NX-01 (Next upgrade) and the SEC/NODE trust-boundary rules were not applied. They would change behaviour, which was out of scope here.
  - `no-console` is off.
  - PR sizes exceed GIT-05's 400 lines. Most of the volume is moved JSX/code; each PR body explains it, and parts are separate commits.
  - Prettier is enforced only on refactored paths (ADR 0002).
- **Partial PRs:** none. No step was skipped for behaviour reasons.
- **Reasoned `eslint-disable`s:** `react-hooks/exhaustive-deps` in about 13 places (game 5, profile 4, misc 4), each with a `-- behaviour preserved` reason, plus `max-params` on 3 legacy facade signatures that tests depend on. These are the first candidates for the fix phase.
- **Ruff per-file ignores:** remain only for engine **test** files, which were frozen.
- **Commit subjects:** created before the consolidation they say `[NN/19]`; PR titles use `[NN/13]` (ADR 0003).
- **Risks to watch:**
  1. React reconciliation differences in the split pages. Rendered HTML was compared byte-for-byte in throwaway harnesses; only whitespace/text-node splits differ (ADR 0222/0243).
  2. Extra microtask boundaries inside server services (no I/O reordering; ADR 0103).
  3. The engine's `STOCKFISH_POOL_SIZE` parse error now fails on importing any engine module (ADR 0304).
  4. `server-only@0.0.1` is the only new runtime dependency.
  5. `readme_first.md:600` still describes private games as created on the Node server.
