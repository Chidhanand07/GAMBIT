## Behaviour changes users will notice

- **Game reviews:** White's moves are scored correctly (1.e4 is no longer an "Inaccuracy"); accuracies change. Old reviews stay wrong until the re-run script is applied (Deploy step 5).
- **The computer opponent (MAVERICK) plays better as Black** (it could choose moves good for its opponent).
- A challenge shows a spinner until the server answers; a refused or timed-out action shows an error toast instead of hanging.
- A player whose connection dropped while searching stays in the queue and still gets matched.
- Analysis depth above 20 is refused (the app sends 18).
