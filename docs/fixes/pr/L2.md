## Behaviour changes users will notice

- Fewer resyncs and flicker on the game page; toggling sound no longer reconnects to the game.
- History navigation: ← from live shows the previous move; → is disabled while live.
- Leaving the lobby while searching takes you out of the queue; you are never pulled into a game you stopped searching for.
- A move, resign or chat the server never confirms shows "The server did not answer…" after 8 s instead of silently doing nothing.
- Offline: a Retry button when the engine fails.
